📸 How to Export as Image

Method 1: Screenshot (Recommended)

1. Open this file in your browser (already open!)

2. Press F11 for fullscreen (optional - for cleaner capture)

3. Use Windows Snipping Tool (Win + Shift + S) to capture the diagram area

4. Save as architecture_diagram.png

Method 2: Browser DevTools

1. Right-click on the diagram → Inspect

2. Right-click on the <svg> element in DevTools

3. Copy → Copy outerHTML

4. Save to a .svg file for vector graphics

Method 3: Print to PDF

1. Press Ctrl + P

2. Select "Save as PDF" as destination

3. Adjust margins and save
